# Politique de confidentialité — AV·WAN

Dernière mise à jour : 15 octobre 2026

**AV·WAN ne collecte aucune donnée personnelle.** Pas de compte, pas de publicité, pas de statistiques d'utilisation, pas de rapport de plantage envoyé. L'app fonctionne hors ligne.

## Ce qui reste sur votre ordinateur

- **Vos projets** (`.avwan`) : là où vous les enregistrez, par défaut dans Documents › AV·WAN.
- **Les données de l'app** : réglages, fichiers récents, composantes perso, listes de canaux DMX, copies de secours et versions précédentes d'un projet. Elles sont rangées dans le dossier de données de l'app :
  - Windows (Microsoft Store) : dans le dossier du paquet, sous `%LOCALAPPDATA%\Packages\` ;
  - Windows (installeur GitHub) : `%APPDATA%\AV·WAN` ;
  - macOS : `~/Library/Application Support/AV·WAN`.

Rien de tout cela n'est envoyé ailleurs. Un projet ne quitte votre ordinateur que si vous le partagez vous-même.

## Connexions réseau

- **Version Microsoft Store** : l'app ne se connecte à rien. Ses mises à jour passent par le Microsoft Store, selon la [déclaration de confidentialité de Microsoft](https://privacy.microsoft.com/fr-ca/privacystatement).
- **Version téléchargée sur GitHub** (macOS et Windows) : l'app vérifie s'il existe une nouvelle version auprès de GitHub, au lancement puis toutes les 4 heures. Cette requête ne contient aucune donnée de vos projets. GitHub reçoit votre adresse IP et la version installée, selon la [déclaration de confidentialité de GitHub](https://docs.github.com/fr/site-policy/privacy-policies/github-general-privacy-statement).
- **Liens** : les liens de l'app (par exemple la page des versions) s'ouvrent dans votre navigateur.

## Effacer vos données

- Désinstaller AV·WAN depuis Windows efface le dossier de données de la version Microsoft Store.
- Pour la version GitHub, supprimez le dossier de données indiqué plus haut.
- Vos projets `.avwan` restent dans Documents jusqu'à ce que vous les supprimiez.

## Privacy policy (English summary)

AV·WAN collects no personal data: no account, no ads, no usage analytics, no crash reports. Projects and app settings stay on your computer. The Microsoft Store version makes no network connections; updates are delivered by the Microsoft Store. The version downloaded from GitHub checks GitHub for updates at launch and every 4 hours; that request contains none of your project data. Contact: [github.com/sashabedard/AV-WAN/issues](https://github.com/sashabedard/AV-WAN/issues).
