AV·WAN

Audio-Video · Wiring, Addressing, Networking — installation guide

Version {{VERSION}}

macOS 13 and later

  1. Open AV-WAN-{{VERSION}}-universal.dmg.
  2. Drag AV·WAN into the Applications folder.
  3. Open AV·WAN from Applications.
  4. The first time, macOS reminds you the app was downloaded from the Internet: click Open.

The app is signed and verified by Apple. It runs on both Intel and Apple Silicon Macs.

Windows 10 and 11

Recommended: Microsoft Store (apps.microsoft.com/detail/9NR2WJRZZ5JG), automatic updates, no warning. Otherwise, the installer:

  1. Run AV-WAN-{{VERSION}}-setup.exe. No administrator rights are needed.
  2. If Windows shows “Windows protected your PC”, click More info, then Run anyway.
  3. AV·WAN opens. A shortcut is added to the Desktop and the Start menu.

This warning appears because the Windows installer is not signed with a paid certificate. It only appears at install time.

Opening a project

Double-click an .avwan file: AV·WAN opens on that project. If another project has unsaved changes, the app asks you first.

Updates

AV·WAN checks for new versions on its own and downloads them in the background. A banner then offers Restart now; otherwise, the update installs the next time you quit. To check right away: Help › Check for Updates…

Unsaved work

AV·WAN saves your project to its file on its own, two seconds after each change: File › Auto Save, on by default. A new project gets its file in the Documents › AV·WAN folder on the first change. To get a file back as it was when you opened it: File › Revert to Opened Version…; this revert can be undone like any other change.

AV·WAN also keeps a backup copy of your project every 30 seconds. After an unexpected shutdown, the start screen offers to restore it.
